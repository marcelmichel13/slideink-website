In 4 Schritten

  1. Panel öffnen

    Tippen Sie auf den SlideInk-Griff am Bildschirmrand oder ziehen Sie ihn zur Mitte.

  2. Notizen machen

    Schreiben Sie mit dem Finger oder einem Eingabestift Zahlen, zeichnen Sie einen Pfeil oder kreisen Sie ein Feld ein.

  3. Panel einklappen und weiterspielen

    Tippen Sie auf den Pfeil zum Einklappen des Panels. Die Notizen werden ausgeblendet und Sie können das Spiel wieder bedienen.

  4. Zu den Notizen zurückkehren

    Wenn Sie sie brauchen, öffnen Sie das Panel wieder. Darin finden Sie Ihre angefangenen Notizen.

Tipps

  • Wenn Sie das Spiel unter den Notizen schlecht sehen, passen Sie die Hintergrund-Deckkraft an.
  • Wenn sich das Spielfeld verschiebt oder ändert, bleiben die Notizen an derselben Stelle des Bildschirms.
  • Wenn Sie die Notizen für später aufheben möchten, tippen Sie auf die Diskette. Sie werden in der Bibliothek gespeichert.
  • Wenn Sie neu anfangen möchten, tippen Sie auf den Papierkorb. Bevor die ganze Notiz gelöscht wird, fragt SlideInk noch einmal nach.

Geht das auch ohne SlideInk?

Ja. Manche Spiele haben eigene Notizen oder einen Bleistiftmodus. SlideInk ist praktisch, wenn Sie diese Möglichkeit nicht haben oder auch etwas anderes notieren möchten.

Häufige Fragen

Werden meine Notizen auch ins Spiel geschrieben?

Nein. Sie bleiben in SlideInk. Eine über dem Sudoku geschriebene Zahl füllt das Feld im Spiel zum Beispiel nicht von selbst aus.

Wann schreibe ich und wann bediene ich das Spiel?

Bei geöffnetem Panel schreiben Sie Notizen. Wenn Sie das Panel einklappen, können Sie weiterspielen.

Ist SlideInk kostenlos?

Ja. Notizen und Zeichnen sind kostenlos. Erinnerungen können Sie 14 Tage lang kostenlos testen. Wenn Sie danach weiter neue erstellen möchten, können Sie SlideInk PRO kaufen. Sie zahlen nur einmal, ohne Abo.

Auf welchen Geräten funktioniert SlideInk?

Auf Smartphones und Tablets mit Android 7 oder neuer. Erlauben Sie beim ersten Start die Einblendung über anderen Apps, damit sich das Panel darüber öffnen kann.
