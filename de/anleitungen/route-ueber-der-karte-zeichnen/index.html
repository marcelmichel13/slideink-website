In 4 Schritten

  1. Karte vorbereiten

    Verschieben und zoomen Sie die Karte so, dass Sie den ganzen Weg sehen, den Sie markieren möchten.

  2. Panel öffnen und Route zeichnen

    Tippen Sie auf den SlideInk-Griff am Bildschirmrand oder ziehen Sie ihn zur Mitte. Zeichnen Sie den Weg, kreisen Sie das Ziel ein oder schreiben Sie die Uhrzeit des Treffens dazu.

  3. Zeichnung speichern

    Tippen Sie auf das Diskettensymbol. Die Zeichnung finden Sie danach in der Bibliothek. Gespeichert wird nur, was Sie gezeichnet und geschrieben haben, ohne die Karte.

  4. Panel einklappen

    Klappen Sie das ausziehbare SlideInk-Panel wieder ein. Danach können Sie die Karte wieder verschieben und zoomen. Die Zeichnung passt sich der Karte aber nicht an.

Tipps

  • Wenn Sie den Weg samt Karte schicken möchten, machen Sie einen Screenshot, solange Sie Karte und Zeichnung sehen. SlideInk schützt gesperrte Notizen vor Screenshots.
  • Wenn Sie die Karte unter der Zeichnung schlecht sehen, passen Sie die Hintergrund-Deckkraft an.
  • Farbe und Stärke des Stifts ändern Sie mit einem Tipp auf das Stiftsymbol.
  • Wenn Sie neu anfangen möchten, tippen Sie auf den Papierkorb. Bevor die ganze Notiz gelöscht wird, fragt SlideInk noch einmal nach.

Geht das auch ohne SlideInk?

Ja. Sie können einen Screenshot der Karte machen und darauf zeichnen. Mit SlideInk zeichnen Sie direkt über der geöffneten Karte.

Häufige Fragen

Was passiert, wenn ich die Karte verschiebe?

Die Zeichnung bleibt an derselben Stelle des Bildschirms und passt dann womöglich nicht mehr zur Route. Bereiten Sie die Karte deshalb vor dem Zeichnen vor.

Wird auch die Karte gespeichert?

Nein. Über Speichern oder Teilen wird nur Ihre Notiz gespeichert oder gesendet. Wenn Sie auch die Karte darunter festhalten möchten, machen Sie einen Screenshot. SlideInk schützt gesperrte Notizen vor Screenshots.

Ist SlideInk kostenlos?

Ja. Notizen und Zeichnen sind kostenlos. Erinnerungen können Sie 14 Tage lang kostenlos testen. Wenn Sie danach weiter neue erstellen möchten, können Sie SlideInk PRO kaufen. Sie zahlen nur einmal, ohne Abo.

Auf welchen Geräten funktioniert SlideInk?

Auf Smartphones und Tablets mit Android 7 oder neuer. Erlauben Sie beim ersten Start die Einblendung über anderen Apps, damit sich das Panel darüber öffnen kann.
