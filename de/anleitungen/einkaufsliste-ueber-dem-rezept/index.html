In 4 Schritten

  1. Panel öffnen

    Tippen Sie auf den SlideInk-Griff am Bildschirmrand oder ziehen Sie ihn zur Mitte.

  2. Notieren, was Sie kaufen müssen

    Schreiben Sie mit dem Finger oder einem Eingabestift direkt über dem Rezept. Wenn Sie lieber die Tastatur verwenden, tippen Sie auf ihr Symbol.

  3. Liste speichern

    Tippen Sie auf das Diskettensymbol. Die Liste wird in der Bibliothek gespeichert. Über „Benennen und einordnen“ können Sie sie zum Beispiel „Einkauf“ nennen.

  4. Liste im Laden öffnen

    Tippen Sie im Panel auf das Buchsymbol. Wählen Sie in der Bibliothek Ihre Liste und sehen Sie nach, was Sie kaufen müssen.

Tipps

  • Markieren Sie die Liste als Favorit, damit Sie sie leichter finden.
  • Mit dem Widget „Notizaktionen“ öffnen Sie die Bibliothek direkt vom Startbildschirm.
  • Wenn Sie das Rezept unter der Liste schlecht sehen, passen Sie die Hintergrund-Deckkraft an.

Geht das auch ohne SlideInk?

Ja. Sie können die Liste auf Papier oder in eine andere Notiz-App schreiben. Mit SlideInk schreiben Sie sie direkt über dem Rezept, ohne App-Wechsel.

Häufige Fragen

Bleibt mir die Liste, wenn ich das Rezept schließe?

Ja. Wenn Sie die Liste speichern, finden Sie sie auch nach dem Schließen des Rezepts in der SlideInk-Bibliothek.

Kann ich die Liste jemandem schicken?

Ja. Schicken Sie sie über Teilen, zum Beispiel in einer Nachricht. Gesendet wird nur Ihre Liste, ohne das Rezept darunter.

Ist SlideInk kostenlos?

Ja. Notizen und Zeichnen sind kostenlos. Erinnerungen können Sie 14 Tage lang kostenlos testen. Wenn Sie danach weiter neue erstellen möchten, können Sie SlideInk PRO kaufen. Sie zahlen nur einmal, ohne Abo.

Auf welchen Geräten funktioniert SlideInk?

Auf Smartphones und Tablets mit Android 7 oder neuer. Erlauben Sie beim ersten Start die Einblendung über anderen Apps, damit sich das Panel darüber öffnen kann.
