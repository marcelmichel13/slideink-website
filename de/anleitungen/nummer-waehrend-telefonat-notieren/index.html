In 4 Schritten

  1. Panel öffnen

    Tippen Sie auf den SlideInk-Griff am Bildschirmrand oder ziehen Sie ihn zur Mitte.

  2. Nummer notieren

    Schreiben Sie sie mit dem Finger oder einem Eingabestift direkt in die Notiz. Sie können dabei weiter telefonieren.

  3. Notiz speichern

    Tippen Sie auf das Diskettensymbol – Notiz speichern. Die Notiz finden Sie danach in der Bibliothek.

  4. Panel einklappen

    Telefonieren Sie weiter. Zur gespeicherten Notiz können Sie jederzeit zurückkehren.

Tipps

  • Schalten Sie den Lautsprecher ein oder nutzen Sie Kopfhörer, damit Sie während des Telefonats schreiben können.
  • Wenn Sie lieber mit der Tastatur schreiben, tippen Sie auf das Tastatursymbol.
  • Genauso notieren Sie einen Termin, eine Adresse, einen Namen oder eine Auftragsnummer.

Geht das auch ohne SlideInk?

Ja. Während eines Telefonats können Sie eine andere Notiz-App öffnen und die Nummer dort notieren. Das Gespräch läuft weiter. Mit SlideInk öffnen Sie die Notiz direkt über dem Anrufbildschirm.

Häufige Fragen

Ist SlideInk kostenlos?

Ja. Notizen und Zeichnen sind kostenlos. Erinnerungen können Sie 14 Tage lang kostenlos testen. Wenn Sie danach weiter neue erstellen möchten, können Sie SlideInk PRO kaufen. Sie zahlen nur einmal, ohne Abo.

Sieht mein Gesprächspartner, was ich schreibe?

Nein. Bei einem normalen Telefonat sehen nur Sie die Notiz.

Auf welchen Geräten funktioniert SlideInk?

Auf Smartphones und Tablets mit Android 7 oder neuer. Erlauben Sie beim ersten Start die Einblendung über anderen Apps. Dadurch können Sie die Notiz auch während eines Telefonats öffnen.
